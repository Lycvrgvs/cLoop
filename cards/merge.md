Merge guideline: a count never chooses; evidence does.
- Compare candidates on reproduced real-run evidence: CORE established first, then all; a regression disqualifies.
- Among the eligible, keep the one that fixes the named cause at its origin with the smallest coherent change. Prefer the candidate that removes over the one that adds.
- Combine candidates only when they are disjoint and run together; a combination is a new candidate and is judged again.
- Never merge on reading alone: run the merged result on real input on HEAD before its council.
